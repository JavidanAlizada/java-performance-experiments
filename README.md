# Java Performance Experiments

Small, runnable experiments behind my articles on JVM performance and concurrency.
Each folder is self-contained: one benchmark, the exact commands, and the numbers I measured.

## Requirements

- JDK 21 or newer
- No build tool needed: each experiment compiles with plain `javac` (see the folder's README)
